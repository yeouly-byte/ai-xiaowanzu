常用术语中英对照 Glossary

英文中文含义
Repository仓库存放项目代码的地方，简称 repo
Commit提交把一次代码修改记录进版本历史
Branch分支从主线分出来独立开发的副本
Main / Master主分支项目的默认主线分支
Merge合并把一个分支的改动并入另一个分支
Fork派生 / 复刻把别人的仓库复制一份到自己账号下
Clone克隆把远程仓库完整下载到本地
Pull Request合并请求请求把你的改动并入目标仓库，简称 PR
Issue问题 / 议题用来报告缺陷或讨论需求的工单
Star星标 / 收藏给项目点赞并收藏，相当于书签
Watch关注订阅仓库动态，有更新会通知你
Fork / Star / Watch派生 / 星标 / 关注仓库右上角三个最常用的按钮
Release发行版正式发布的版本，通常附带下载包
Tag标签给某个提交打的记号，如 v1.0
Actions自动化流程自动构建、测试、部署的流水线
Pages静态网站托管用仓库内容免费发布网站（本页就是）
Gist代码片段分享单段代码的轻量方式
Raw原始文件查看不经过渲染的纯文本内容
Blame追溯查看每一行代码是谁、何时改的
Diff差异对比显示改动前后的区别
README说明文档仓库首页展示的项目介绍文件
License许可证规定别人能如何使用你的代码
Token访问令牌代替密码用于命令行或程序的凭证
